# Questionnaire maître de cadrage fondateur

| Champ | Valeur |
|---|---|
| Statut | Working — collecte en cours |
| Propriétaire des réponses | Fondateur |
| Facilitation et consolidation | Codex |
| Créé le | 2026-07-23 |
| Portée | Quintessences, GSIE, Forge, GeoSylva, Hub, Ignis et applications secondaires |

> Ce questionnaire est un outil de collecte, pas une source de vérité.
> Une réponse ne devient une décision du projet qu'après validation explicite,
> puis enregistrement dans une décision, une RFC, une spécification ou une
> roadmap selon sa nature.

## Mode d'emploi

Les réponses peuvent être données dans le chat, bloc par bloc. Il n'est pas
nécessaire de répondre à tout en une fois.

Pour chaque question, utiliser si possible ce format :

```text
Q00.01 — Réponse :
Pourquoi :
Priorité : critique / haute / moyenne / basse
Confiance : certaine / probable / intuition / inconnue
À vérifier avec :
```

Réponses parfaitement acceptables :

- `INCONNU` : l'information manque réellement ;
- `À TESTER` : une expérimentation ou un entretien utilisateur est nécessaire ;
- `À DÉCIDER PLUS TARD` : la décision n'est pas nécessaire au prochain jalon ;
- `NON` : le besoin est explicitement exclu ;
- `HYPOTHÈSE` : la réponse n'est pas encore étayée.

Lorsqu'une question demande un classement, aucun ex æquo n'est autorisé sauf
mention contraire. Lorsqu'elle demande une note, utiliser une échelle de 0 à 5.

## Méthode de consolidation après réponse

Les réponses seront transformées, après validation du fondateur, en cinq
livrables distincts :

1. une **carte du portefeuille produit** définissant le rôle et le statut de
   chaque application ;
2. une **vision produit consolidée** avec utilisateurs, problèmes, promesse et
   limites ;
3. une **roadmap par tranches verticales démontrables**, avec critères de
   sortie ;
4. une **matrice de décisions et d'hypothèses à tester** ;
5. un **plan qualité de livraison** couvrant produit, UX, science, sécurité,
   exploitation et documentation.

Les réponses ne seront jamais copiées aveuglément dans les sources de vérité :
les contradictions seront signalées, les hypothèses seront séparées des
décisions et chaque changement structurant sera soumis à validation.
