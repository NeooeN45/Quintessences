|---|---|

| **Statut** | Validé — contrôle implémenté le 2026-08-30 |
| **Date** | 2026-08-30 |
| **Décideur** | Fondateur |
| **Périmètre** | GSIE API — Data Registry, Forge, 14 moteurs et GSIE-Bench |
| **Précédents** | RFC-0038, DEC-000059, DEC-000078 |

## Constat

Le registre SCI-001 et les adapters Data Registry couvrent déjà six familles
opérationnelles, mais les inventaires de recherche D1 à D8 décrivent un
ensemble beaucoup plus vaste de sources. La documentation seule ne prouve ni
le droit d'accès, ni le schéma, ni la reproductibilité, ni l'intégration d'un
moteur.

## Décision

La liste des 14 moteurs est contrôlée par une matrice exécutable unique. Une
dépendance directe doit passer par l'adapter déclaré ou par le handoff Forge
versionné. Les moteurs transverses reçoivent seulement des données déjà
normalisées et qualifiées.

Les candidats de recherche sont catalogués comme candidats et ne peuvent pas
ouvrir d'egress, lancer un fetch, alimenter un entraînement ou être promus
parce qu'ils sont mentionnés dans un document. Les états `QUERY`, `FETCH` et
`PROMOTION` restent trois portes distinctes.

Le contrôle est exécuté sans réseau par `audit_engine_source_matrix.py` et par
le workflow GitHub `source-governance.yml`. Le contrôle SCI-001 des 23 sources
reste obligatoire et complémentaire.

## Preuves et limites

- la matrice contient les 14 contrats GSIE-Bench ;
- les dépendances directes déclarées sont IGN, Météo des forêts, SoilGrids
  WCS, GBIF Species, TAXREF miroir GBIF, Bellifa et IFN Forge ;
- le REST bêta SoilGrids est refusé par test ;
- une source inconnue est refusée par test ;
- les contrôles ciblés de matrice, qualification et couverture passent à
  13/13 avec le Python système isolé ;
- le venv local n'est pas exploitable sur ce poste et la suite complète doit
  être rejouée dans l'environnement verrouillé GitHub ;
- cette décision ne qualifie pas juridiquement les sources candidates et ne
  publie aucun SLO fournisseur ou campagne de production à grande échelle.
