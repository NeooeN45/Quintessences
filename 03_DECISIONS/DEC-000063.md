# DEC-000063 — Désynchroniser le recyclage des workers API

| Champ | Valeur |
|---|---|
| **ID** | DEC-000063 |
| **Statut** | Validated |
| **Date** | 2026-08-10 |
| **Décideur** | Camille Perraudeau (Fondateur) |
| **Périmètre** | Recyclage et continuité des workers API |

## Contexte

Le test grandeur nature de DEC-000062 mesurait environ 19 requêtes/s et un
p95 très élevé via le port publié par Docker Desktop. Le profilage interne a
ensuite révélé deux phénomènes distincts :

- le transfert Windows vers le port Docker limite fortement la mesure hôte ;
- les cinq workers, réglés à `1000 + 0–50` requêtes, se recyclaient presque
  ensemble et interrompaient certaines connexions persistantes.

## Décision

- porter `max_requests` de 1 000 à 5 000 ;
- porter `max_requests_jitter` de 50 à 5 000 ;
- rendre ces deux valeurs surchargeables par variables d'environnement ;
- refuser au démarrage toute valeur nulle ou négative ;
- conserver le keep-alive à cinq secondes ; sa désactivation a échoué au test ;
- ne pas présenter Docker Desktop comme une mesure de capacité de production.

La continuité sans coupure pendant un recyclage devra être assurée en
production par plusieurs réplicas derrière la bordure et des contrôles de
retrait gracieux. Le réglage présent réduit la fréquence et empêche la sortie
groupée, mais un conteneur unique ne constitue pas une haute disponibilité.

## Preuves

- ancien réglage, 6 000 requêtes, concurrence 5 : 5 992 succès, trois
  déconnexions, cinq timeouts, 123,38 req/s ;
- nouveau réglage, même campagne : 6 000 succès, zéro erreur, 669,34 req/s,
  p95 11,47 ms ;
- campagne longue, 40 000 requêtes : 39 996 succès, zéro timeout, quatre
  déconnexions correspondant à quatre recyclages étalés, p95 33,30 ms ;
- expérience `keepalive=0`, 12 000 requêtes : seulement 11 338 succès ; option
  rejetée et rollback immédiat ;
- API restaurée saine : `/health` et `/ready` à 200, zéro restart, zéro OOM.

Le détail reproductible se trouve dans
`GSIE/API/docs/PERFORMANCE_CAPACITY_PROFILE_2026-08-10.md`.
