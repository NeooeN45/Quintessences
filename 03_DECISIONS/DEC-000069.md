## Contexte

DEC-000068 a fermé quatre identités historiques trop agrégées. L'audit SQL
réel a confirmé que les versions persistées sont `metadata_only`, sans
opération, couche ou jeu constitutif permettant une scission fiable.

## Décision

Autoriser uniquement un dry-run local et déterministe comparant le manifeste
historique au manifeste I0 candidat. Le résultat doit :

- marquer `UNRESOLVED` toute migration sans preuve de contenu ;
- marquer `PRESERVE_LINEAGE` le micro-extrait SoilGrids DEC-000061 ;
- exposer séparément les propositions futures étayées par les adapters ;
- garantir `writes=0`, `fetch_enabled=false` et `promotion_allowed=false`.

## Gardes

- aucun accès PostgreSQL, MinIO ou fournisseur depuis le script ;
- aucune réécriture de slug, alias, checksum, URI ou statut ;
- aucune ouverture de FETCH ;
- aucune promotion ou application de manifeste ;
- toute suite ambiguë reste soumise à une validation humaine ultérieure.

## Résultat

Le dry-run du 13 août 2026 produit trois décisions `UNRESOLVED` (GBIF,
IGN/API Carto, Météo-France), un `PRESERVE_LINEAGE` SoilGrids et deux
propositions futures limitées à GBIF Species API et Météo des forêts.
