# DEC-000050 — IA forestière on-device et multi-tier

| Champ | Valeur |
|---|---|
| **ID** | DEC-000050 |
| **Statut** | Validé |
| **Date** | 2026-08-03 |
| **Décideur** | Camille Perraudeau (Fondateur) |
| **RFC liée** | RFC-0034 |
| **Supersède** | Aucun |
| **Préserve** | DEC-000049, CON-001, CON-004, CON-005, ADR-009 |
| **Nature** | Décision d'architecture IA et de choix de modèles |

## Décision

GeoSylva 3.0 introduit un assistant IA forestier multi-tier consolidant
les visions existantes (VOLUME_CALCULATION_NEXT_GEN §10,
RESEARCH_OPPORTUNITIES §3, VISION_LLM_SPECIALISES). Trois tiers sont adoptés :

- **T1 Mobile** : SmolLM3 3B (quantifié INT4, ~1.6 GB), runtime ONNX
  Runtime, offline total. Assistant vocal, explication des calculs
  locaux, identification essence (TFLite + PureForest).
- **T2 Edge** : Mistral 7B (AWQ 4-bit), vLLM/NIM sur Jetson Orin, Wi-Fi
  local. RAG documentation forestière, raisonnement intermédiaire.
- **T3 Serveur** : Mistral 7B servé (puis Phi-4-reasoning 14B quand dédifféré
  par RFC-0031), vLLM sur GPU serveur via `gsie-ai-gateway` (RFC-0019).
  Raisonnement profond via moteurs GSIE, RAG scientifique pgvector.

Le LLM ne produit jamais une valeur numérique forestière de lui-même : il
invoque un moteur GSIE (RFC-0033) et cite le résultat. Une sortie LLM non
citée est un défaut bloquant (ADR-009).

## Choix retenus

| Élément | Choix | Justification |
|---|---|---|
| Modèle T1 | SmolLM3 3B (Apache 2.0) | Licence permissive, taille compacte, français suffisant, mise à jour active |
| Runtime T1 | ONNX Runtime | Portabilité CPU/GPU/NPU, API Android stable |
| RAG local T1 | SQLite-vec (< 200 MB) | Offline, mise à jour via packs |
| Modèle T2 | Mistral 7B (AWQ 4-bit) | Apache 2.0, raisonnement intermédiaire |
| Modèle T3 | Mistral 7B servé (puis Phi-4-reasoning 14B) | RFC-0019, vLLM |
| Identification essence | TFLite + PureForest IGN (INT8, < 50 MB) | RFC-0018 volet hors-ligne |
| Saisie vocale | Vosk FR offline | Souveraineté, offline |
| Adaptateurs LoRA | `GeoSylva-Forest` T2/T3 uniquement | T1 reste généraliste (contrainte mémoire) |
| Distribution | Packs de données (§9 GEOSYLVA-003) | Pas de Play Store pour les modèles |

## Garde-fous

- **ADR-009** : toute sortie LLM contient `source_reference` ou invoque
  un moteur. Défaut bloquant.
- **GSIE-CON-001** : le forestier reste le décideur. Toute recommandation
  est contournable.
- **GSIE-CON-004** : toute conclusion est explicable (chaîne d'inférence).
- **Offline-first** : T1 fonctionne sans réseau. T2/T3 sont
  amplificateurs, jamais dépendances.
- **RGPD** : audio brut supprimé après transcription sauf accord spécifique.
  Pas de donnée personnelle envoyée au serveur sans consentement.
- **Banc GSIE-Eval-FR** : tout modèle doit passer le banc avant activation
  opérationnelle (justesse citations, refus d'inventer, format enveloppe,
  français forestier, latence).

## Phase

Phase P5 de la roadmap GeoSylva 3.0 (GEOSYLVA-003 §12.4). Dépendances :
P4 (connexion GSIE Serveur, RFC-0033/DEC-000049) terminé.
`gsie-ai-gateway` (RFC-0019) implémenté pour T3.

## Preuves d'acceptation attendues

1. Banc `GSIE-Eval-FR` validé pour SmolLM3 3B INT4 (T1).
2. Tests RAG local (recherche, citation, refus d'inventer).
3. Tests cascade T1→T3 (délégation explicite, traçage en session).
4. Tests identification essence (TFLite, dégradation gracieuse, score < seuil).
5. Tests assistant vocal (Vosk FR, confirmation visuelle, RGPD audio).
6. Tests RGPD (suppression audio, consentement, pas de fuite serveur).
7. Tests de performance (latence T1 < 500 ms, mémoire < 1.5 GB RAM).
