## Décision

Le compte local Quintessences fournit dès cette tranche la consultation et
la modification du profil, la vérification de l'adresse électronique et la
récupération du mot de passe. GeoSylva expose ces fonctions sans rendre le
compte obligatoire pour les usages forestiers hors ligne.

Les actions sensibles reposent sur des codes aléatoires à usage unique,
hachés avec Argon2id en base et valables quinze minutes. Une réinitialisation
du mot de passe incrémente la version de session du compte et révoque ainsi
les refresh tokens émis avant l'opération.

## Garanties de sécurité

- les demandes de récupération répondent de manière identique pour une
  adresse connue ou inconnue ;
- le serveur ne journalise ni adresse électronique, ni code, ni mot de passe,
  ni jeton ;
- un code consommé, expiré ou incorrect est refusé ;
- les courriels transactionnels utilisent SMTP chiffré en production ;
- Mailpit est réservé au développement local, lié à l'interface de boucle
  locale et sans donnée réelle ;
- le rôle applicatif conserve l'interdiction de suppression physique des
  données d'identité.

## Conséquences

- une cinquième table d'identité conserve uniquement les empreintes et
  métadonnées temporaires des codes d'action ;
- le client mobile permet de modifier le nom affiché, demander et confirmer
  une vérification, puis demander et confirmer une récupération ;
- le changement de mot de passe ferme les sessions antérieures ;
- la configuration d'un relais SMTP réel est obligatoire avant ouverture
  publique ;
- l'authentification multifacteur, les passkeys, le centre de comptes web et
  la fédération professionnelle restent des tranches distinctes.

## Critères d'acceptation

1. le cycle inscription → profil → vérification → récupération → reconnexion
   fonctionne sur PostgreSQL réel ;
2. une ancienne session est refusée après récupération du mot de passe ;
3. les réponses de demande ne permettent pas d'énumérer les comptes ;
4. GeoSylva conserve toutes ses fonctions locales lorsque l'API est absente ;
5. la configuration locale fournit un serveur de courrier captif et
   reproductible.
