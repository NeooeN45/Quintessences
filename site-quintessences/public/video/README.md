# Vidéo de fond du hero

Dépose ici :
- `hero.mp4` (H.264, requis)
- `hero.webm` (optionnel, meilleure compression)
- `hero-poster.jpg` (image affichée avant chargement de la vidéo)

Recommandations : vidéo courte en boucle (10-20s), sans son (elle est
lue en muet), compressée (<5 Mo idéalement) pour ne pas pénaliser
SITE-X-001 (LCD < 2,5s). Tant qu'aucun fichier n'est présent, le
dégradé animé de repli reste seul visible (VideoBackdrop.astro).
